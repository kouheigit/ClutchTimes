## システム概要

### プロジェクト情報
- **システム名**: kpg-laravel（会員制宿泊予約システム）
- **対象施設**: GLAMDAY STYLE TEITAKU 空ノ庭（軽井沢）
- **開発体制**: フィリピン・セブ島チームとの国際共同開発

### 技術スタック
- **バックエンド**: Laravel 8.x、PHP 8.0/8.1
- **データベース**: MySQL 8.0
- **インフラ**: Docker Compose
- **認証**: Laravel Breeze
- **管理画面**: Laravel Admin
- **決済**: Veritrans TGMDK API
- **外部API**: OpenWeatherMap、Google Maps Directions API

### システム規模
- **テーブル数**: 40テーブル
- **モデル数**: 26モデル
- **マイグレーション**: 75ファイル
- **コントローラー**: 60個（フロント34個、管理画面26個）
- **ビューファイル**: 166個

### 主要機能
1. ユーザー管理（会員登録、認証、プロフィール）
2. ホテル管理（複数施設対応）
3. 予約管理（FIXDAY/FREEDAY、カレンダー連携）
4. サービス注文・カート機能
5. クレジットカード決済（Veritrans）
6. 会員ポイントシステム
7. 招待機能（ゲストユーザー）
8. 管理画面（Laravel Admin）
9. お知らせ・情報配信
10. メール通知機能
