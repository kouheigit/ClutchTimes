## 技術経歴書記載時の重要ポイント

### ✅ 必ず記載すべき項目

1. **プロジェクト名** - 「コーポレートサイト開発（Laravel + React版）」など
2. **期間** - 開発期間（開始月〜終了月、または期間）
3. **役割** - 自分の役割（フルスタックエンジニア、フロントエンドエンジニアなど）
4. **使用技術** - 主要な技術スタック（7-10個程度）
5. **担当業務** - 自分が担当した具体的な業務（箇条書き推奨）
6. **実装内容** - 具体的に実装した機能・技術
7. **成果** - 技術的な成果や数値（可能であれば）

### ✅ 技術スタックの記載順序

1. **バックエンド** - Laravel 10.x
2. **フロントエンド** - React 18.x
3. **ビルドツール** - Vite
4. **CSS** - Tailwind CSS v4
5. **ルーティング** - React Router v6
6. **状態管理** - Context API / React Query
7. **アニメーション** - Framer Motion
8. **HTTP** - Axios
9. **テスト** - Jest + React Testing Library
10. **インフラ** - KUSANAGI, Nginx

### ✅ 記載のコツ

- **簡潔に**: 1プロジェクトあたり8-12行程度が目安
- **技術を明確に**: 使用した技術スタックを具体的に記載
- **担当業務を具体的に**: 「開発」ではなく「React 18.xによるフロントエンド開発」など具体的に
- **成果を数値で**: 可能であれば「70%短縮」「50%向上」など数値で記載
- **Reactの特徴を強調**: コンポーネント設計、再利用性、パフォーマンス最適化など

### ❌ 避けるべき表現

- 「様々な」「多くの」などの曖昧な表現
- 技術スタックの羅列のみ（実装内容がない）
- プロジェクトの説明のみ（自分の担当業務がない）
- 過度に専門的な用語の多用
- 虚偽の成果・数値
