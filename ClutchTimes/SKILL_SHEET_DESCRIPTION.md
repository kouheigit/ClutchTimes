## スキルシート記載時の重要ポイント

### ✅ 必ず記載すべき項目

1. **プロジェクト名** - 簡潔で分かりやすい名称
2. **期間** - 開発期間（開始月〜終了月、または期間）
3. **役割** - 自分の役割（バックエンドエンジニア、リーダーなど）
4. **チーム規模** - チーム人数（オプションだが記載推奨）
5. **使用技術** - 主要な技術スタック（5-7個程度）
6. **担当業務** - 自分が担当した具体的な業務（箇条書き推奨）
7. **実装内容** - 具体的に実装した機能・技術
8. **成果** - 技術的な成果や数値（可能であれば）

### ✅ スキルシート記載のコツ

- **簡潔に**: 1プロジェクトあたり5-10行程度が目安
- **技術を明確に**: 使用した技術スタックを具体的に記載
- **担当業務を具体的に**: 「開発」ではなく「認証システム実装」など具体的に
- **成果を数値で**: 可能であれば「3倍向上」「50%改善」など数値で記載
- **スキルをアピール**: 自分のスキルが分かるように記載

### ✅ 技術スタックの記載順序

1. **言語** - Python 3.9
2. **フレームワーク** - Django 4.2
3. **データベース** - PostgreSQL 14
4. **インフラ** - Docker, Nginx, Gunicorn
5. **その他** - Redis, pytest など

### ❌ 避けるべき表現

- 「様々な」「多くの」などの曖昧な表現
- 技術スタックの羅列のみ（実装内容がない）
- プロジェクトの説明のみ（自分の担当業務がない）
- 過度に専門的な用語の多用
- 虚偽の成果・数値
